# ☀️ 朝の健康・タスク確認アシスタント

Streamlit と Google Gemini API を活用して作成した、社員の健康状態とタスクを確認するためのAIチャットボットです。
毎朝の始業前にAIとチャットするだけで、自然な会話の中から必要な情報をヒアリングし、日報としてまとめてくれます。

## ✨ アピールポイント・オリジナリティ（こだわった点）
既存のチャットボットや定型フォームでのアンケートにはない、AIとプログラミングを組み合わせた独自の工夫を取り入れています。

- **1. 会話の裏側で動く「隠しアラート」システム**
  AIがユーザーの返答から「発熱」「二日酔い」「極端な寝不足」などの健康リスクを検知すると、AIの返答内にシステム検知用の暗号（`[ALERT]`タグ）を忍ばせるようにプロンプトを設計しています。プログラム側でそのタグを読み取ってユーザーの画面からは隠しつつ、裏側で上司への報告アラートを起動する、という「LLMとプログラムの連携処理」を実現しました。
- **2. 条件分岐による「優しい深掘り」ヒアリング**
  単にタスクを羅列して聞くのではなく、「体調が悪い」「アルコールを飲んだ」という回答があった場合のみ、業務の話に移る前にAIが理由や詳細を気遣って深掘りするようにシステムを組んでいます。機械的ではない、人間に寄り添うツールを目指しました。
- **3. 外部API連携による「元気になるひとこと」**
  外部の天気API（wttr.in）からその日のリアルタイムな天気を自動取得し、裏側でAIに教えています。これにより、会話の最後に「今日の天気と、1日を前向きに始められるパーソナライズされた励ましの言葉」を自然な形で生成させています。

## 🌟 主な機能
- **🗣️ 自然な会話フロー:** 体調、睡眠の質、アルコール摂取の有無、本日のタスクをAIが順番に優しく聞き出します。
- **📋 日報の自動作成:** ヒアリングが終わると、本日の内容を箇条書きで綺麗にまとめます。
- **⚠️ エスカレーション機能:** 健康リスク検知時、画面に上司への報告を促すエラー通知を表示します。
- **⛅ 天気情報の自動取得:** 大阪の天気を自動で取得し、会話の最後に添えてくれます。

## 🛠️ 使用技術
- Python 3
- Streamlit (Web UIフレームワーク)
- Google Gemini API (gemini-3.8-flash)
- wttr.in (天気情報の取得 API)

## 🔐 セキュリティについて
このアプリはStreamlitの `st.secrets` 機能を利用しているため、ソースコード上（GitHub上）にAPIキーを直接書き込むことなく、安全に公開・運用できる設計になっています。
